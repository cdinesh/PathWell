# Product definition

PathWell is a personal AI chief of staff for coordinated life and wealth decisions. The primary persona is Alex Morgan: a 31-year-old professional with solid income, several competing goals, a self-directed portfolio, and limited time to reconcile finance, career, and travel choices.

## Week 1 scope

The MVP proves one cohesive loop: establish identity and preferences, show a unified seeded dashboard, navigate usable domain prototypes, and ask a cross-domain question that Finance and Travel agents resolve through an orchestrator. It includes document metadata/upload architecture, shared goals, user scoping, explainable structured output, and explicit approval levels.

## Core journeys

1. Register with validated identity fields and optional documents, then progressively onboard.
2. Review a single dashboard of financial health, goals, portfolio, career, and travel.
3. Explore a domain and invoke context-aware suggested prompts.
4. Ask whether a trip is affordable without delaying a financial goal; inspect assumptions and alternatives.
5. Add or update a shared goal and control preferences/documents.

## Implementation sequence

Schema and seed → user-scoped APIs → agent contracts/workflow → reusable app shell → registration/onboarding → dashboard/domain pages → advisor activity/result → quality gates.
